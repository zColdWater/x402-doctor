x402 error invalid_exact_evm_payload_authorization_valid_after

Authorization is not valid yet (validAfter is in the future).

What the spec says

Payment authorization is not yet valid (before validAfter timestamp).

Common causes

  • validAfter was set to now on a client whose clock runs ahead of the facilitator's.
  • validAfter is in milliseconds instead of seconds (a 13-digit number).

How to fix it

Set validAfter a little in the past (for example now - 600 seconds), in Unix seconds.
