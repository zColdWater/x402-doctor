x402 error code reference

The error codes a facilitator or server returns in invalidReason (verify) or errorReason (settle), what they mean, and how to fix them.

  • insufficient_funds · Payer does not hold enough tokens
  • invalid_exact_evm_payload_authorization_valid_after · Authorization is not valid yet (validAfter is in the future)
  • invalid_exact_evm_payload_authorization_valid_before · Authorization has expired (validBefore has passed)
  • invalid_exact_evm_payload_authorization_value_mismatch · Signed value does not match the required amount
  • invalid_exact_evm_payload_signature · Signature does not verify
  • invalid_exact_evm_payload_recipient_mismatch · authorization.to is not the payTo address
  • invalid_network · Network is not supported
  • invalid_payload · Payment payload is malformed
  • invalid_payment_requirements · Payment requirements are malformed
  • invalid_scheme · Scheme is invalid
  • unsupported_scheme · Facilitator does not support this scheme
  • invalid_x402_version · Protocol version is not supported
  • invalid_transaction_state · Settlement transaction failed or was rejected
  • unexpected_verify_error · Facilitator error during verification
  • unexpected_settle_error · Facilitator error during settlement
  • settlement_pending · Settlement broadcast but not confirmed yet

Got one of these? Paste your headers into x402 Doctor to find the cause. It runs offline in your browser.

Descriptions follow the error code table of the x402 v2 specification; causes and fixes are the Doctor's notes. Facilitators may also return codes of their own.
